# المكتبة القضائية الذكية — حزمة كودكس

مهارة عربية وموصل MCP للبحث في الأحكام المنشورة بالبوابة القانونية لوزارة العدل السعودية وقراءة نصوصها مع روابط المصادر. هذا مشروع مستقل؛ لا يمثل الوزارة ولا يدعي اعتمادها.

## الاستخدام المختصر

بعد التثبيت وإعادة تحميل كودكس، اكتب:

```text
$qada ابحث عن حكم تجاري استخدم المادة الستين من نظام الإثبات
```

أو اطلب: «ابحث في المكتبة القضائية الذكية عن فسخ عقد ثم اقرأ أول حكم». المهارة توجه البحث؛ الاتصال الفعلي تنفذه أدوات MCP المرفقة.

## المتطلبات

- كودكس وواجهة `codex` متاحة في PATH.
- Node.js 22 أو أحدث.
- اتصال بالإنترنت وإتاحة البوابة الرسمية من جهاز المستخدم.

## التثبيت

فك الضغط في مجلد ثابت، وافتح الطرفية داخله:

```powershell
node scripts/install.mjs --dry-run
node scripts/install.mjs --install
```

يعرض الأمر الأول ما سيُثبت دون تغيير الجهاز. يسجل الثاني موصلًا محليًا باسم `saudi_judicial_portal` باستخدام Node الموجود لدى المستخدم، وينسخ المهارة إلى مجلد مهارات كودكس. لا ينزل أي برامج ولا يطلب كلمة مرور. إذا كان الاسم موجودًا يتوقف؛ افحص الإعداد الحالي قبل استخدام `--replace`. لا تنقل مجلد الحزمة بعد التسجيل لأن كودكس يشغّل الموصل من مساره.

أعد فتح كودكس، ثم اطلب بحثًا وفتح حكم من نتائجه. لا تكفي حالة enabled لإثبات الوصول؛ `portal_status` يثبت نجاح البحث والتفاصيل في عملية الموصل الحالية فقط.

إذا كان عميلك يدعم تثبيت حزم Agent Plugins، تتضمن الحزمة `plugin.json` و`mcp.json` والمهارة؛ استخدم طريقة التثبيت المناسبة لعميلك بدل تنفيذ المثبت أيضًا. لا تسجل نسختين من الموصل.

## الفحص

```powershell
node --test
```

الاختبارات محلية باستجابات محاكاة؛ لا تتصل بالوزارة. مسار البحث والقراءة تحقق حيًا في 2026-10-17 من داخل كودكس، لكن المصدر قد يرفض طلبات لاحقة أو يغير صيغة البيانات. توقف عند الرفض ولا تحوله إلى نتائج فارغة أو تدع نجاحًا غير متحقق.

## الخصوصية والنطاق

الموصل يرسل إلى نطاق `laws-gateway.moj.gov.sa` عبارة البحث ومعاملاته أو معرف الحكم، ورأس اللغة العربية وقيمة زائر حرفية `token` مرصودة في تطبيق الويب العام. لا يستخدم مفاتيح حساب أو ملفات تعريف ارتباط أو أرقام هوية. لا تدخل بيانات عملاء أو وقائع سرية في عبارة البحث. لا يحفظ الموصل نتائجك في ملفات أو قاعدة بيانات ولا يجمع قياسات استخدام؛ قد يحتفظ كودكس ومشغّل البوابة بطلبات ونتائج وفق سياساتهما.

الأدوات للقراءة فقط: لا ترفع دعاوى ولا تعدل بيانات الوزارة ولا تصدر قرارًا قانونيًا ملزمًا. افصل نص المحكمة عن التحليل، وراجع الوقائع والحالة الإجرائية قبل الاستدلال بالحكم.

## المشاركة والنشر

المستودع العام للمشروع: [المكتبة القضائية الذكية](https://github.com/aabdullalshehri-hub/smart-judicial-library). نزّل المصدر من قائمة Code ثم Download ZIP، أو استنسخ المستودع، ثم اتبع خطوات التثبيت أعلاه. لم يُضف ترخيص لإعادة الاستخدام؛ الإتاحة العامة وحدها لا تمنح ترخيصًا. الحزمة ليست معتمدة في دليل إضافات كودكس.

الحزمة لا تحتوي بيانات جهاز المطور أو سجلات محادثاته أو نسخ أحكام كاملة. يتطلب النشر الرسمي في دليل الإضافات استكمال هوية الناشر ومعلومات العرض والسياسات والدعم ووجهة الإصدار المناسبة للخادم المحلي.

## الإزالة

```powershell
codex mcp remove saudi_judicial_portal
```

أزل المهارة `qada` من مجلد مهارات كودكس إذا لم تعد تحتاج إليها. الإزالة لا تتواصل مع الوزارة.
